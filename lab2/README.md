## Вывод  
Эксперимент с изменением порта показал, что официальный образ контейнера hello от Google не имеет жёстко зашитого порта, а слушает порт, указанный в переменной окружения PORT, которую Cloud Run автоматически передаёт контейнеру при запуске. Поэтому изменение порта в настройках Cloud Run с 8080 на 8090 не привело к поломке сервиса — контейнер автоматически адаптировался. Для демонстрации проблемы несоответствия порта необходимо использовать образ с жёстко заданным портом.
